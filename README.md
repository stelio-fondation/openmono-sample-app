# OpenMonoAgent — Sample .NET Project

A minimal .NET 10 console app used to verify the end-to-end
[OpenMonoAgent](https://www.openmonoagent.ai) local AI coding setup.

## What this project demonstrates

- **Local LLM inference** on GPU (RTX 3060, 8 GB VRAM) via `llama.cpp` in Docker
- **OpenMonoAgent** running locally — no API key, no cloud, no billing
- **Model**: Qwen3-8B Q4_K_M (~5 GB, fully GPU-offloaded, ~20 tok/s)
- **Integration verified**: the Fibonacci function below was generated by the model

## Setup

### 1. Install OpenMonoAgent

Open a PowerShell terminal and run the installer inside WSL:

```bash
wsl bash -c "bash <(curl -fsSL https://raw.githubusercontent.com/StartupHakk/OpenMonoAgent.ai/refs/heads/main/get-openmono.sh)"
```

The installer:
- Clones the repo to `~/openmono.ai`
- Detects your hardware (GPU or CPU fallback)
- Downloads the appropriate model
- Builds Docker images and starts `llama-server`

### 2. Enable GPU acceleration (NVIDIA)

```bash
# Add NVIDIA container toolkit repo and configure Docker runtime
wsl bash -c "
  curl -fsSL https://nvidia.github.io/libnvidia-container/gpgkey \
    | gpg --dearmor -o /usr/share/keyrings/nvidia-container-toolkit-keyring.gpg
  curl -s -L https://nvidia.github.io/libnvidia-container/stable/deb/nvidia-container-toolkit.list \
    | sed 's#deb https://#deb [signed-by=/usr/share/keyrings/nvidia-container-toolkit-keyring.gpg] https://#g' \
    | tee /etc/apt/sources.list.d/nvidia-container-toolkit.list
  apt-get update -qq && apt-get install -y nvidia-container-toolkit
  nvidia-ctk runtime configure --runtime=docker
  systemctl restart docker
"
```

Verify GPU is accessible from Docker:

```bash
wsl bash -c "docker run --rm --gpus all nvidia/cuda:12.3.0-base-ubuntu22.04 nvidia-smi"
```

### 3. Use a model that fits your VRAM

The default GPU model (27B, 16 GB) overflows 8 GB VRAM. Download the lighter
**Qwen3-8B Q4_K_M** (~5 GB) instead:

```bash
wsl bash -c "hf download Qwen/Qwen3-8B-GGUF Qwen3-8B-Q4_K_M.gguf \
  --local-dir /root/openmono.ai/models/"
```

Then update `/root/openmono.ai/docker/docker-compose.override.yml`:

```yaml
services:
  llama-server:
    image: ghcr.io/ggml-org/llama.cpp:server-cuda
    command: >
      --model /models/Qwen3-8B-Q4_K_M.gguf
      --alias Qwen3-8B
      --host 0.0.0.0
      --port 7474
      --ctx-size 32768
      --threads 14
      --n-gpu-layers 99
      --flash-attn on
      --cache-type-k q8_0
      --cache-type-v q8_0
      --batch-size 2048
      --ubatch-size 1024
      --parallel 1
      --jinja
      --reasoning off
      --metrics
    environment:
      - NVIDIA_VISIBLE_DEVICES=all
      - NVIDIA_DRIVER_CAPABILITIES=compute,utility
    deploy:
      resources:
        reservations:
          devices:
            - driver: nvidia
              count: 1
              capabilities: [gpu]
```

Restart the server:

```bash
wsl bash -c "docker restart llama-server"
```

Verify health and VRAM usage (~1355 MiB for Qwen3-8B):

```bash
wsl bash -c "
  docker inspect --format='{{.State.Health.Status}}' llama-server
  nvidia-smi --query-gpu=memory.used,memory.total --format=csv,noheader
"
```

### 4. Run the agent

Open a WSL terminal and navigate to your project:

```bash
# From Windows PowerShell
wsl

# Inside WSL
source ~/.bashrc
WORKSPACE=/path/to/your/project openmono agent
```

> **Tip:** The agent TUI requires an interactive TTY.
> Always launch it from a WSL shell opened directly, not via `wsl bash -c`.

## Quick API test

You can test the llama-server directly without the TUI:

```bash
curl -s http://localhost:7474/v1/chat/completions \
  -H 'Content-Type: application/json' \
  -d '{"model":"Qwen3-8B","messages":[{"role":"user","content":"Say hello in one sentence."}],"max_tokens":50}' \
  | python3 -c "import sys,json; r=json.load(sys.stdin); print(r[\"choices\"][0][\"message\"][\"content\"])"
```

## Project code

`Program.cs` — generated by OpenMonoAgent (Qwen3-8B) in response to the prompt
*"Add a Fibonacci function and call Fibonacci(10)"*:

```csharp
Console.WriteLine("Hello, World!");
Console.WriteLine(Fibonacci(10));  // prints 55

int Fibonacci(int n)
{
    if (n <= 1)
        return n;
    return Fibonacci(n - 1) + Fibonacci(n - 2);
}
```
